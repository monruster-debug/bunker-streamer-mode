УБЕЖИЩЕ 42 STREAM v0.4.0

УСТАНОВКА
1. Распакуйте архив в постоянную папку.
2. chrome://extensions -> Режим разработчика -> Загрузить распакованное расширение -> выберите папку с manifest.json.
3. Откройте живую комнату https://shelter42.ru/online/game и обновите вкладку.
4. Нажмите значок расширения -> Проверьте подключение -> Открыть экран стрима.
5. Нажмите «Настройка камер» на экране стрима.

ИСТОЧНИК 1: DISCORD ИЛИ ОКНО OBS
Откройте Discord с вебкамерами в сетке 4x3. Нажмите «Захватить окно Discord / OBS», выберите окно/вкладку с камерной сеткой и подтвердите разрешение браузера.
При необходимости обрежьте заголовок/боковые панели процентными отступами. Вверху каждой карточки в режиме настроек назначьте номер источника (камера 1-12).

ИСТОЧНИК 2: OBS VIRTUAL CAMERA
В OBS соберите 12 камер в одной сцене и нажмите Start Virtual Camera.
В расширении выберите OBS Virtual Camera из списка устройств (если список пуст, разрешите камеру кнопкой и обновите список) и нажмите «Выбрать камеру / OBS Virtual Camera».
Важно: браузер видит ОДИН общий видеопоток, который делится на ячейки. Это не 12 независимых каналов Discord.

OBS ДЛЯ СТРИМА
Откройте экран стрима в обычной вкладке Chrome и после предоставления разрешения захватите эту вкладку/окно в OBS через Window Capture / Display Capture. Существующий Browser Source OBS не наследует разрешение захвата, выданное Chrome, и не разделяет с ним MediaStream. Нельзя рассчитывать на автоматическую работу камер в Browser Source.
Рекомендуется скрыть блок настроек кнопкой «Закрыть» до начала эфира.

ОГРАНИЧЕНИЯ
- Видеозахват работает только пока открыта эта вкладка оверлея. После её перезагрузки разрешение нужно запросить снова.
- Видеопотоки локальны, никуда не загружаются. Нужны согласие и разрешение участников на трансляцию.
- Порядок 12 камер должен оставаться фиксированным. Если Discord переставляет участников, проверьте соответствие номеров.
- При захвате полного экрана можно получить рекурсивное изображение. Предпочтителен выбор конкретного окна Discord или окна OBS со сценой.
- Закрытые карты игры не считываются из личного интерфейса.
- После изменения селекторов сайта или DOM требуется доработка content.js.
- Расширение не управляет OBS и не захватывает внутренние видеопотоки Discord напрямую.
- Данная версия не проверялась с реальным OBS/Discord в контейнере: протестируйте на ПК.
